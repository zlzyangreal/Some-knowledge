## Agent 类优质开源项目

| 项目 | 一句话 | 适合看什么 |
| --- | --- | --- |
| Voyager（AI 玩 MC） | LLM 驱动在 Minecraft 里自主探索、写代码、积累技能库 | 技能库（skill library）+ 自我反思循环 |
| AutoGPT | 最早的“自主 Agent”范式 | 任务分解、工具调用、记忆 |
| LangChain / LlamaIndex | Agent 与 RAG 框架 | 工具注册、检索链路 |
| OpenHands（原 OpenDevin） | 能写代码、跑命令的软件工程 Agent | sandbox 执行、反馈闭环 |
| SWE-agent | 面向 GitHub issue 自动修复 | 代码检索 + 编辑动作空间 |
| MetaGPT | 多角色协作（产品/架构/开发） | 角色分工与 SOP |
| Claude Code / Gemini CLI / Codex CLI | 终端里的编码 Agent | 工具权限、上下文管理 |

## 看这类项目时的重点

1. **动作空间**：它能做什么（写文件、跑命令、调 API），决定了能力上限。
2. **反馈闭环**：执行结果怎么回到模型（编译错误、测试失败、运行日志），这是能不能自我纠错的关键。
3. **记忆**：短期（对话）、长期（向量库/技能库）、工作区（文件）三层怎么分工。
4. **权限与安全**：能不能删文件、能不能联网、要不要人工确认。
