# 1. 下载
## 1.1 环境配置
首先检查是否有docker
```bash
docker --version
```
[下载链接](https://www.docker.com/get-started/)
- [[Docker下载windows11]]
终端检查`Node.js`是否存在
```bash
# 调出终端
# 在任意文件夹上方输入cmd，最好不要使用 powershell而是cmd
# 查询
node -v
```
[下载链接](https://nodejs.org/en/download)
下载安装 Windows 安装程序(.msi)
- [[下载Nodejs]]
## 1.2 下载
```bash
npm pack @google/gemini-cli
npm install -g ./google-gemini-cli-1.x.x.tgz
```
# 2. 启动
```bash
gemini
```
