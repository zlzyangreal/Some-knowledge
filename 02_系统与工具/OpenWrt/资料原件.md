## 编译流程要点（make menuconfig）

```bash
# 1. 准备环境（Ubuntu）
sudo apt install -y build-essential libncurses5-dev gawk git subversion

# 2. 拉源码（以官方 23.05 为例）
git clone https://git.openwrt.org/openwrt/openwrt.git
cd openwrt && git checkout v23.05.3
./scripts/feeds update -a && ./scripts/feeds install -a

# 3. 选目标平台与软件包
make menuconfig
#   Target System      -> 芯片平台（如 MediaTek）
#   Subtarget          -> 具体板型
#   Target Profile     -> 设备型号
#   Target Images      -> 输出格式（squashfs / ext4）
#   LuCI               -> Web 管理界面（Collections -> luci）

# 4. 编译（首次会下载工具链，很慢）
make -j$(nproc) V=s
```

产物在 `bin/targets/<平台>/<子平台>/` 下。

## menuconfig 里最该改的几项

| 位置 | 作用 |
| --- | --- |
| Target Images → squashfs | 默认只读根 + overlay，恢复出厂最方便 |
| Target Images → ext4 | 可写根，调试期方便，但刷机体积大 |
| Base system → dnsmasq / firewall | 路由核心服务，别乱关 |
| LuCI → Collections | 装 Web 界面 |
| Network → 各类驱动 | 网卡/WiFi 驱动，漏选就没有无线 |

## 只编单个包（省时间）

```bash
make package/luci-app-xxx/compile V=s
make package/luci-app-xxx/{clean,compile} V=s   # 先清理再编
```
