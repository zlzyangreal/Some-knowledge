# 帮助指令

> 目标不是背命令，而是**忘了参数时 30 秒内查出来**。

## 1. 四个层次

| 命令 | 内容 | 什么时候用 |
| --- | --- | --- |
| `cmd --help` | 简版参数列表 | 最快，够用就走 |
| `man cmd` | 完整手册（分章节） | 要看细节、退出码、文件格式 |
| `info cmd` | GNU 的超链接手册 | man 太简略时 |
| `man -k 关键字` / `apropos` | 按关键字搜所有手册 | 只记得功能不记得命令名 |

```bash
ls --help | head -20
man ls            # 里面按 / 搜索，n 下一个，q 退出
man -k "copy file"   # 找"复制文件"相关命令
```

## 2. man 手册的分区

| 区 | 内容 | 例子 |
| --- | --- | --- |
| 1 | 用户命令 | `man 1 ls` |
| 2 | 系统调用 | `man 2 open` |
| 3 | 库函数 | `man 3 printf` |
| 5 | 文件格式 | `man 5 fstab` |
| 8 | 管理命令 | `man 8 mount` |

同名冲突时（如 `printf` 既是命令也是库函数）必须指定区号。

## 3. 命令自带的帮助子命令

```bash
git help commit          # 等价于 man git-commit
git commit --help
python3 -c "help(str.split)"   # Python 内置帮助
pip --help
cmake --help-command add_executable
```

## 4. 更好用的替代品

```bash
sudo apt install tldr      # 只给常用示例，比 man 好读
tldr tar
```

## 5. 实用技巧

- `man` 里 `h` 看操作说明，`/关键词` 搜索，`q` 退出。
- `man -w 命令` 能看到手册文件的实际路径。
- 大部分命令的退出码：`0` 成功，非 0 失败；`echo $?` 查看上一条的退出码。
