# 3. 三大类滤波器怎么选

| 类型 | 核心思想 | 适合 | 代价 |
| --- | --- | --- | --- |
| FIR（有限冲激响应） | 只用输入的历史值加权求和 | 线性相位、绝对稳定 | 阶数高、延迟大 |
| IIR（无限冲激响应） | 输出也参与反馈 | 同样指标下阶数低、计算省 | 相位非线性，可能不稳定 |
| 自适应滤波（LMS/RLS） | 权值随误差自动调整 | 噪声/回声特性未知或缓变 | 需要参考信号，收敛要时间 |

## 3.1 移动平均 / 一阶低通（工程上最常用）

```c
// 一阶低通：alpha 越小越平滑、相位滞后越大
float y = 0.0f;
float lowpass(float x, float alpha) {          // alpha = dt / (RC + dt)
    y = alpha * x + (1.0f - alpha) * y;
    return y;
}

// 滑动平均：N 点缓存求和
#define N 16
float buf[N]; int idx = 0; float sum = 0;
float moving_avg(float x) {
    sum -= buf[idx];
    buf[idx] = x;
    sum += x;
    idx = (idx + 1) % N;
    return sum / N;
}
```

## 3.2 卡尔曼滤波

最优线性估计：用“预测 + 观测”两个不确定量按方差加权融合。适合带噪声的传感器（IMU、测距、目标框）。
详见 [[卡尔曼滤波器]] 与代码 [[卡尔曼滤波器代码实现]]。

## 3.3 LMS 自适应滤波

```c
// 最简单的 LMS：w 随误差方向调整
for (int n = 0; n < LEN; ++n) {
    float y = dot(w, x + n, TAP);
    float e = d[n] - y;              // d 是期望信号（参考）
    for (int k = 0; k < TAP; ++k)
        w[k] += mu * e * x[n + k];   // mu 决定收敛速度与稳定性
}
```

## 3.4 谱减法（语音去噪）

在频域估计噪声幅度谱并从含噪谱里减掉，再反变换回时域。实现简单，但会引入“音乐噪声”。
见 [[各类滤波算法]] 的谱减法小节。

## 4. 选择口诀

1. 只看幅频特性、要线性相位 → FIR。
2. 算力紧张（单片机）→ 一阶/二阶 IIR。
3. 噪声统计未知、要跟随变化 → LMS / 卡尔曼。
4. 离线处理、追求质量 → 频域滤波（FFT 后改幅度谱再 IFFT）。
