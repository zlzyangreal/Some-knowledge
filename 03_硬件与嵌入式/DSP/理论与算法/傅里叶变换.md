# 1. 几个必须先定下来的量

采样率 `fs`、点数 `N`、频率分辨率 `Δf = fs / N`。三者确定后，第 k 个频点对应的频率是 `k * fs / N`，
能分析的**最高频率是 `fs / 2`**（奈奎斯特），超过就会混叠——抗混叠要在 ADC 前加模拟低通。

例：`fs = 1024 Hz`、`N = 1024` → `Δf = 1 Hz`，能看 0 ~ 512 Hz，第 100 个点就是 100 Hz。

# 3. 单片机上的实数 FFT

常见做法是借助 CMSIS-DSP（Cortex-M）或自己写 radix-2：

```c
#include "arm_math.h"

#define N 1024
float32_t in[N * 2];      // 交错存放：实部、虚部、实部、虚部 …
float32_t mag[N / 2];

void fft_once(void) {
    arm_rfft_fast_instance_f32 inst;
    arm_rfft_fast_init_f32(&inst, N);
    arm_rfft_fast_f32(&inst, in, in, 0);          // 0 = 正变换
    arm_cmplx_mag_f32(in, mag, N / 2);            // 求幅度谱
}
```

要点：

1. **输入必须是 2N 长度**的数组（实部 + 虚部交错），这就是上面那篇“为什么要把数组扩成双倍并交错填 0”的原因。
2. 结果只取前 `N/2` 个点，后半是共轭对称，没新信息。
3. 加窗（汉宁/汉明）能压旁瓣泄漏，但会降低幅值精度，需要按窗函数补偿系数。
4. 频率估计用插值（抛物线插值 / 相位差法）能把精度提到远小于 `Δf`。

# 4. 频谱能看出什么、看不出什么

- 能看出：有哪些频率成分、各自强度、噪声基底。
- 看不出：这些频率成分的**相位**（幅度谱丢失了相位），所以不能从单边幅度谱还原波形；
  要还原必须保留复数结果。这也是“为什么说变换后只能得到频率信息”的原因。
- 时变信号（频率随时间变）要用短时傅里叶（STFT）或小波，见 [[小波变换的背景]]、[[多分辨率展开]]。

# 5. 常用变体

| 变体 | 用途 |
| --- | --- |
| DFT / FFT | 稳态信号的频谱 |
| STFT | 时频分析（语音、振动） |
| DCT | 图像/音频压缩（JPEG、MP3） |
| 小波变换 | 多尺度、突变检测 |
