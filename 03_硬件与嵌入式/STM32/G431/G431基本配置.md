## 3. 时钟树要配到 170 MHz

G431 的时钟路径：`HSI(16M) 或 HSE(8M) → PLL → SYSCLK 170M`，再分频给各总线：

| 总线 | 最高频率 | 说明 |
| --- | --- | --- |
| SYSCLK | 170 MHz | 内核主频 |
| AHB (HCLK) | 170 MHz | 内存、DMA |
| APB1 (PCLK1) | 170 MHz（定时器 x2） | 部分外设 |
| APB2 (PCLK2) | 170 MHz | 高速外设 |

CubeMX 里把 `PLL Source` 选 HSE、`PLLM` 等参数填好，`HCLK` 直接输 170 回车让它自动算，
最后确认 `Clock Configuration` 里没有红色告警。

## 4. 生成后要检查的三处

```c
/* 1. 时钟是否真的生效 */
SystemClock_Config();               // main() 里第一件事
// 用 HAL_RCC_GetHCLKFreq() 打印出来确认是 170000000

/* 2. 调试口是否保留（否则下载一次就锁死，只能接 BOOT0 救） */
// SYS → Debug: Serial Wire

/* 3. 中断优先级分组 */
HAL_Init();                          // 默认 NVIC_PRIORITYGROUP_4
```

## 5. 工程骨架建议

```
Core/Inc, Core/Src      CubeMX 生成的 HAL 代码
BSP/                    板级驱动（led.c、key.c、lcd.c、adc.c）
App/                    业务逻辑（状态机、协议解析）
```

把“CubeMX 生成的”和“自己写的”分开，重新生成代码时才不会被覆盖（用 `USER CODE BEGIN/END` 保护区）。

## 6. 常见问题

| 现象 | 原因 |
| --- | --- |
| 下载一次后再也连不上 | 没开 Serial Wire，SWD 引脚被复用成 GPIO；按住复位再点下载 |
| 串口乱码 | 时钟不对，波特率算错 |
| 程序不进 main | 启动文件/堆栈设置不对，或 Boot 引脚电平错 |
| 定时器周期差一倍 | APB 预分频不为 1 时定时器时钟会 x2 |
