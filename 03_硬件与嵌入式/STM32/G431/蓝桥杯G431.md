## 板子资源速记

- 内核：Cortex-M4F @ 170 MHz，带 FPU 和 DSP 指令（做 FFT/滤波很关键）。
- 存储：128 KB Flash / 32 KB RAM（RAM 紧张，大数组要想清楚）。
- 常见外设：4 个 LED、4 个按键、LCD（并口/SPI）、2 个 DAC、多路 ADC、USART、I2C、SPI、定时器（含高级定时器 TIM1）。

## 蓝桥杯常见考点

| 考点 | 关键点 |
| --- | --- |
| 按键长短按 | 定时器扫描 + 状态机，别用 `HAL_Delay` 阻塞 |
| PWM 调光/调速 | 改 `CCR` 而不是重启定时器；注意互补输出与死区 |
| 输入捕获测频 | 双边沿捕获 + 两次计数值差；高频用“测频法”，低频用“测周法” |
| ADC 多通道 | 用 DMA + 扫描模式，别一个个轮询 |
| 串口协议帧 | 帧头+长度+数据+校验，用空闲中断或 DMA 收不定长 |
| LCD 刷新 | 局部刷新 + 双缓冲，整屏刷会闪 |

## 常见坑

1. 时钟没配对 → 串口波特率全错、定时器周期不对。
2. 忘记 `HAL_Init()` 里开中断优先级分组，导致优先级不生效。
3. LCD 与 LED 抢引脚 → 见 [[LCD使LED亮灭混乱]]。
4. 中断里调用 `HAL_Delay` → 直接卡死（SysTick 优先级低于当前中断时）。
