# G431外部触发中断

> 目标：按键按下触发 EXTI 中断，在回调里做最短的处理（置标志位），主循环再消费。

## 1. CubeMX 配置

1. 选引脚（如 `PA0`）→ 设为 `GPIO_EXTI0`。
2. `System Core → GPIO` → 选中该引脚：
   - **GPIO mode**：`External Interrupt Mode with Rising edge trigger detection`（按键按下接地就用 Falling）
   - **Pull-up/Pull-down**：按键接 GND 时选 `Pull-up`
3. `System Core → NVIC` → 勾选 `EXTI line0 interrupt` → 设抢占优先级（一般给中等，别比 SysTick 高）。
4. 生成代码。

## 2. 生成的代码结构

```c
/* stm32g4xx_it.c —— 中断入口，CubeMX 自动生成，不要改逻辑 */
void EXTI0_IRQHandler(void) {
    HAL_GPIO_EXTI_IRQHandler(GPIO_PIN_0);   // 内部会清标志并调回调
}
```

## 3. 写回调（用户代码区）

```c
/* main.c 里 USER CODE BEGIN 4 */
volatile uint8_t g_key_flag = 0;

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
    if (GPIO_Pin == GPIO_PIN_0) {
        g_key_flag = 1;          // 只置标志，别在这里做耗时操作
    }
}

/* 主循环 */
while (1) {
    if (g_key_flag) {
        g_key_flag = 0;
        HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
    }
}
```

## 4. 必须知道的三个坑

1. **抖动**：机械按键会进多次中断。硬件加 100 nF 电容，或软件里“进中断后关闭 EXTI、定时器 20 ms 后再开”。
2. **HAL_GPIO_EXTI_Callback 是弱函数**：自己实现时函数名必须一模一样，否则不会被调用。
3. **中断里不能用 HAL_Delay**：`HAL_Delay` 依赖 SysTick 中断，若当前中断优先级更高会死等。

## 5. 消抖的定时器写法

```c
void HAL_GPIO_EXTI_Callback(uint16_t pin) {
    if (pin == KEY_Pin) {
        HAL_TIM_Base_Start_IT(&htim7);   // 启动 20 ms 单次定时
        __HAL_GPIO_EXTI_DISABLE_IT(KEY_Pin);  // 消抖期间屏蔽
    }
}

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef* htim) {
    if (htim->Instance == TIM7) {
        HAL_TIM_Base_Stop_IT(&htim7);
        if (HAL_GPIO_ReadPin(KEY_GPIO_Port, KEY_Pin) == GPIO_PIN_RESET)
            g_key_flag = 1;              // 仍然是按下状态，判定有效
        __HAL_GPIO_EXTI_CLEAR_IT(KEY_Pin);
        __HAL_GPIO_EXTI_ENABLE_IT(KEY_Pin);
    }
}
```
