## 背景

香橙派（Orange Pi 5 / 5B 等 RK3588 板子）板载 WiFi 常见是 **AP6275P**（Broadcom BCM43752 系列，走 PCIe）。
官方镜像一般已带驱动，自己编译内核或换系统时要手动处理。

## 检查当前状态

```bash
lspci | grep -i network          # 能不能看到 PCIe 网卡
ip a                             # 有没有 wlan0
dmesg | grep -i -E "brcm|ap6275|wlan"
rfkill list                      # 是否被软/硬阻塞
```

## 加载驱动

```bash
# 驱动模块名通常为 bcmdhd 或 brcmfmac
sudo modprobe bcmdhd
# 或
sudo modprobe brcmfmac

# 开机自动加载
echo "bcmdhd" | sudo tee -a /etc/modules
```

固件缺失时（`dmesg` 里报 `Direct firmware load failed`），把 `brcmfmac43752-pcie.bin` 之类固件放到
`/lib/firmware/brcm/` 下。

## 连 WiFi（两种方式）

```bash
# 方式一：nmcli（推荐，NetworkManager 环境）
nmcli device wifi list
nmcli device wifi connect "SSID" password "密码"

# 方式二：wpa_supplicant（精简系统）
sudo wpa_passphrase "SSID" "密码" | sudo tee /etc/wpa_supplicant.conf
sudo wpa_supplicant -B -i wlan0 -c /etc/wpa_supplicant.conf
sudo dhclient wlan0
```

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 只有 `eth0` 没有 `wlan0` | 驱动没加载或固件缺失，看 `dmesg` |
| 能扫到但连不上 | 密码/加密方式（WPA2 vs WPA3）、信道（部分国家码不支持 12/13 信道） |
| 连上但没网 | DHCP 没拿到地址：`sudo dhclient wlan0`；或 `resolv.conf` 没 DNS |
| 频繁掉线 | 省电模式：`iw dev wlan0 set power_save off` |
| 5G 频段没有 | 国家码未设：`iw reg set CN` |
