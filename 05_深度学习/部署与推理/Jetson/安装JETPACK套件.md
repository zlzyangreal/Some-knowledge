Jetpack 是 [Nvidia](https://so.csdn.net/so/search?q=Nvidia&spm=1001.2101.3001.7020)为 [Jetson](https://so.csdn.net/so/search?q=Jetson&spm=1001.2101.3001.7020)系列开发板开发的一款软件开发包，常用的开发工具基本都包括了，并在在安装 Jetpack的时候，会自动的将匹配版本的CUDA、cuDNN、TensorRT等安装好
在jetson上输入
```bash
sudo apt update
sudo apt install nvidia-jetpack
```
安装完输入` sudo jetson_release `进行查询
