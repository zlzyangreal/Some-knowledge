# 1.`torch.load` 
PyTorch 框架中的一个函数，用于**加载之前保存的模型参数或者整个模型的状态**
# 2.`Module.load_state_dict` 
PyTorch 中的一个方法，用于加载模型的参数到一个神经网络模块（`Module`）中。这个方法是 **PyTorch 模型保存和加载机制的核心部分**。
# 3.torch.utils.data.DataLoader
它提供了一个迭代器，用于批量加载数据。`DataLoader` 可以高效地将数据集（`Dataset` 对象）中的数据加载到内存中，并支持自动打乱数据顺序、多线程数据加载等特性，是深度学习训练过程中不可或缺的组件。
# 4.`torch.no_grad()`
一个上下文管理器，它用于暂时禁用梯度计算。当你在训练神经网络时，通常需要计算梯度来更新模型的权重，这是通过调用`.backward()`方法实现的。然而，在某些情况下，比如在进行模型推理或评估时，你不需要计算梯度，因为这些操作不涉及权重的更新。
# 5.`torch.mean` 
用于计算张量（tensor）的平均值。这个函数可以沿着指定的维度（dimension）进行平均值的计算，如果没有指定维度，则计算整个张量的元素平均值。
# 6.`torch.cat`
用于将多个张量（tensors）拼接在一起。这个函数提供了一种方便的方式来合并具有相同形状的张量，或者沿着指定的维度合并形状不同的张量。
# 7.torch.eye
用于创建一个给定大小的二维张量，其中对角线上的元素是 1，其余元素是 0。这种矩阵被称为单位矩阵或恒等矩阵。
# 9.torch.cov
计算张量协方差矩阵的函数。它接受一个二维张量作为输入，其中每一行通常代表一个观测值，每一列代表一个变量，然后计算这些变量之间的协方差。
# 10.`F.unfold` 
它属于 `torch.nn.functional` 模块，用于将一个多维张量（通常是四维的，例如图像张量）"展开"成一系列的局部块（patches）。这个操作通常用于实现卷积操作，尤其是在空间维度上。
`F.unfold` 的工作原理是从输入张量中提取大小为 `kernel_size` 的局部块，步长为 `stride`。这些局部块可以被看作是输入张量的窗口视图，它们在空间上是连续的。展开操作不会改变局部块内部的数据，但是会改变张量的整体形状。
- `dilation`（可选）：一个整数或整数元组，表示局部块之间的间距。默认为1。
- `padding`（可选）：一个整数或整数元组，表示在输入张量的周围填充的零的数量。默认为0。
- `stride`（可选）：一个整数或整数元组，表示局部块之间的步长。默认为1。
> [!解释] 解释
> 想象你有一张图片，`F.unfold` 就像是一个窗口，你可以用它来覆盖图片，然后提取出窗口覆盖的区域。这个窗口的大小由 `kernel_size` 决定，步长 `stride` 决定了你每次移动窗口的距离。
> 这里是一个具体的例子：
> **假设图片**：假设你有一张 4x4 的图片，你想要使用一个 2x2 的窗口来查看这张图片。
>  **设置窗口大小**：你设置 kernel_size=2，这意味着你的窗口是 2 行 2 列。 
>  **设置步长**：你设置 stride=1，这意味着你每次移动窗口时，窗口会向右移动一个像素。 
>  **展开操作**：当你从图片的左上角开始，使用这个窗口覆盖图片，然后提取出窗口覆盖的区域。接着，你将窗口向右移动一个像素，再次提取出区域。这个过程会一直重复，直到你覆盖了整张图片。 
>  **结果**：最终，你得到的不是一个完整的图片，而是许多小的 2x2 区域。这些区域被排列成一个新的形状，例如，如果原始图片是 4x4，使用 2x2 的窗口和步长为 1 展开后，你会得到一个形状为 (16, 4) 的数组，其中 16 是因为 4x4 的图片可以提取出 16 个 2x2 的区域，4 是因为每个区域有 4 个像素。
# 11.F.fold
用于实现一种称为 "折叠" (folding) 的操作。折叠操作是 `unfold` 操作的逆过程，通常用于在卷积神经网络（CNN）中进行特征图的下采样或上采样。
`unfold` 操作将一个多维张量分割成多个小块，而 `fold` 操作则将这些小块重新组合成一个较小的张量。这通常用于实现跨步卷积（transposed convolution）或有时称为分数步卷积（fractionally-strided convolution）。
# 13.`view` 
用于重新排列（reshape）张量的形状而不改变其数据。`view` 函数是不可变的（不会改变原始数据），它返回一个新的张量，该张量与原始张量共享相同的内存空间，但是具有不同的形状。
