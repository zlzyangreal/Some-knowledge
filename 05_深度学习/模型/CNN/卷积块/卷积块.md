## 卷积模块的演进脉络

| 阶段 | 代表 | 解决什么 |
| --- | --- | --- |
| 标准卷积 | Conv 3×3 / 5×5 | 提特征 |
| 分组/可分离 | MobileNet 的 DW+PW、ShuffleNet | 降算力 |
| 多尺度 | Inception、ASPP、SPP/SPPF | 不同感受野融合 |
| 注意力加权 | SE、CBAM、EMA、CA、SimAM | 让重要通道/位置权重更大 |
| 动态/自适应 | CondConv、ODConv、DyConv | 卷积核随输入变化 |
| 大核 | RepLKNet、大核深度卷积 | 用大感受野替代堆叠小核 |

## ODConv（增强型卷积）

给卷积核加上**四维注意力**：卷积核空间维度、输入通道、输出通道、卷积核数量，四个方向的注意力相乘后加权卷积核。
效果是“同一层里不同位置用不同的有效卷积核”，比 CondConv 更细粒度。

```python
class ODConv2d(nn.Module):
    def __init__(self, in_c, out_c, k=3, stride=1):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(out_c, in_c, k, k))
        # 这里只示意：实际还要接一个注意力分支产出 4 个维度的系数
        self.att = nn.Sequential(nn.AdaptiveAvgPool2d(1), nn.Conv2d(in_c, out_c, 1))
    def forward(self, x):
        w = self.weight * self.att(x).sigmoid()      # 简化版通道加权
        return F.conv2d(x, w, stride=self.stride, padding=self.weight.shape[-1] // 2)
```

## RFAConv（创新型动态卷积）

先用 `k×k` 卷积**预测感受野内的空间注意力**，再用它去调制卷积核——把“看哪里”和“怎么卷”解耦，
在不显著增加参数的前提下提升大核卷积的有效感受野。

## 用不用改卷积的建议

1. 先确认 baseline 不是欠训练/数据有问题——大多数“换模块涨点”其实是训练技巧带来的。
2. 只在**目标尺度差异大**或**小目标多**时优先考虑多尺度/大核/注意力模块。
3. 替换后必须看**推理耗时**：ODConv/RFAConv 都带额外分支，端侧可能不划算。
4. 论文里对比要控制变量：只改模块，其余超参、数据、增强完全一致。
