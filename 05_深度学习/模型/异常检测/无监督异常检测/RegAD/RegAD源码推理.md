# 1.参数输入
![[Screenshot 2024-06-10 203050.png]]
 1. `--obj`
- **作用**：指定要使用的对象类。这个参数用于选择要处理的特定对象类别。
- **文件中的用法**：
    - 用于加载特定对象类的数据集。
    - 用于构建检查点文件路径和支持集文件路径。
2. `--data_type`
- **作用**：指定数据集类型。在此代码中没有直接用到，但可以用来区分不同类型的数据集。
3. `--data_path`
- **作用**：指定数据集的路径。
- **文件中的用法**：
    - 用于加载训练和测试数据集。
 4. `--epochs`
- **作用**：指定最大训练轮数。
- **文件中的用法**：
    - 用于训练过程中控制训练的轮数。在当前代码中未直接使用，因为主要关注测试过程。
 5. `--batch_size`
- **作用**：指定批处理大小。
- **文件中的用法**：
    - 用于加载数据集时设置批处理大小。在测试过程中没有直接使用，因为测试批大小被硬编码为1。
 6. `--img_size`
- **作用**：指定输入图像的大小。
- **文件中的用法**：
    - 用于调整图像大小以适应模型输入。
 7. `--lr`
- **作用**：指定学习率。
- **文件中的用法**：
    - 用于训练过程中的优化器。在当前代码中未直接使用，因为主要关注测试过程。
 8. `--momentum`
- **作用**：指定动量。
- **文件中的用法**：
    - 用于训练过程中的优化器。在当前代码中未直接使用，因为主要关注测试过程。
 9. `--seed`
- **作用**：指定随机种子，用于确保实验的可重复性。
- **文件中的用法**：
    - 设置随机种子以确保结果可复现。
 10. `--shot`
- **作用**：指定few-shot学习中的shot数。
- **文件中的用法**：
    - 用于加载few-shot支持集和构建检查点文件路径。
 11. `--inferences`
- **作用**：指定每次推理的轮数。
- **文件中的用法**：
    - 控制推理过程的轮数。
 12. `--stn_mode`
- **作用**：指定STN（空间变换网络）的模式，用于数据增强。
- **文件中的用法**：
    - 在创建STN网络时传递此参数。

## 4.1优化数据加载过程，使其更适合当前的硬件环境(Cuda)
```python
use_cuda = torch.cuda.is_available()
kwargs = {'num_workers': 4, 'pin_memory': True} if use_cuda else {}
```
- 这行代码使用三元条件运算符（也称为条件表达式）根据 `use_cuda` 的值来创建一个字典 `kwargs`。
    - 如果 `use_cuda` 为 `True`（即可以使用 GPU），`kwargs` 将被设置为包含两个键值对的字典：
        - `'num_workers': 4`：当使用 `DataLoader` 加载数据时，`num_workers` 参数指定了用**于数据加载的工作进程数量**。这里设置为 4，意味着会有 4 个工作进程并行加载数据，这可以提高数据加载的效率。
        - `'pin_memory': True`：当设置为 `True` 时，如果数据加载到 CUDA 设备上，`pin_memory` 会暗示 `DataLoader` 将数据保留在锁页内存中，这可以加快将数据从 CPU 到 GPU 的传输速度。
    - 如果 `use_cuda` 为 `False`（即不使用 GPU），`kwargs` 将被设置为空字典 `{}`，意味着不会应用这些特定的 `DataLoader` 参数。
