# 1. 追踪器 TOPIC
现有大多数为：单一特征追踪器、序列追踪器
- 序列追踪器实现方法：利用一种特征来初步筛选一些关联候选对象，使用另一种特征作为主要的关联指标，旨在避免由两种特征可能引发的匹配冲突问题
	- 缺陷：没有充分利用两种特征的优势，出现，过滤导致跟踪缺失
本文提出：**TOPIC结合了运动特征和外观特征** -> 能够根据运动程度自动选择更优的特征作为分配指标。
- 提出依据：（1）每个特征在特定场景中都有其优势；（2）运动速度与运动和外观特征的有效性密切相关。
1、TOPIC 同时使用运动和外观特征作为分配指标，类似于对匹配结果进行“合并”（减少假阴性）  
2、TOPIC 根据运动级别自动选择更优的匹配项，而非过滤冲突项（从而减少假阴性）
# 2. 数据集 BEE24
现有数据集不具备
- 问题：不同的对象移动方式相似，个体运动强度低且在帧间变化不大
该数据集在两个关键方面展现了复杂运动模式：  
（1）帧内不同对象之间的运动多样性；
（2）不同帧中单个物体运动的显著差异
# 3. 增强模块AARM
能够提高不同物体表示之间的区分度，并增强同一物体在不同帧中的表示的相似性。
