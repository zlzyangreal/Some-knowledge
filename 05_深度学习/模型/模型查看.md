## Netron：看结构最直观

在线版 <https://netron.app/> 直接拖文件进去，支持 `.onnx`、`.pt`(TorchScript)、`.pb`、`.tflite`、`.rknn`、`.mlmodel`。

能看出什么：

- 每层的算子类型、输入输出张量形状（`[1,3,640,640]` 这类）
- 卷积的 `kernel/stride/padding/group`
- 权重是否被常量折叠（`Constant` 节点）
- 哪些地方有 `Reshape`/`Transpose`（部署时最容易被这些卡住）

看不出什么：训练超参、数据增强、后处理逻辑（这些不在图里）。

## 命令行/代码里看

```python
import torch

# 1. 打印参数量与结构
model = torch.load("model.pt", map_location="cpu")
print(model)
total = sum(p.numel() for p in model.parameters())
print(f"params: {total/1e6:.2f} M")

# 2. 每层输入输出形状（需要样例输入）
from torchsummary import summary          # pip install torchsummary
summary(model, input_size=(3, 224, 224))

# 3. 算子级统计
from thop import profile                  # pip install thop
flops, params = profile(model, inputs=(torch.randn(1, 3, 224, 224),))
print(f"FLOPs: {flops/1e9:.2f} G")

# 4. 导出 ONNX 后用 onnx 库检查
import onnx
m = onnx.load("model.onnx")
onnx.checker.check_model(m)
print([n.op_type for n in m.graph.node][:20])
```

## 常见用途

| 目的 | 做法 |
| --- | --- |
| 确认导出前后结构一致 | 分别用 Netron 打开 `.pt` 与 `.onnx` 对照 |
| 找性能瓶颈 | 看 1×1 卷积、`Concat`、`Reshape` 是否密集 |
| 估显存 | 参数量 × 4 字节（fp32）+ 激活值 |
| 查输入输出名 | ONNX 的 `graph.input/output` 名字要写进部署代码 |
