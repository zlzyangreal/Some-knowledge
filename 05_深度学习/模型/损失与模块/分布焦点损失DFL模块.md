# 1. 本文出发点
单阶段检测器通常将目标检测视为密集分类和定位（即边界框回归）的过程

边界框的表示被建模为一个简单的狄拉克δ分布，这种表达方式被用于密集型探测器逐渐引领了物体检测的潮流  
具体来讲：预测额外的定位质量（例如，IoU 分数或中心度分数）会在将质量评估（通常与分类置信度相乘）与分类置信度结合（作为最终得分）用于推理过程中非最大值抑制（NMS）的排序过程时，带来检测精度的一致性提升。
这样带来两个问题
（1）训练和推理过程中质量估计和分类的使用不一致（即分别训练但在测试中综合使用）  
（2）在存在模糊性和不确定性（这在复杂的场景中很常见）的情况下，定位使用的狄拉克δ分布不够灵活  
## 1.1 在训练和推理过程中，定位质量评估和分类得分的使用方式不一致
1. 定位质量评估和分类得分通常是独立训练的，但在推理过程中则被综合使用（例如乘法运算）  
![[DFL1.png]]
2. 定位质量评估的监督仅针对正样本进行，但这并不可靠，因为负样本可能会获得更高的质量预测，而这种预测可能不受控制地更高
![[DFL2.png]]
**这两个因素导致了训练和测试之间的差距，并有可能降低检测性能，例如，在非最大值抑制（NMS）过程中，具有随机高质量评分的负实例可能会排在具有较低质量预测的正实例之前。**
## 1.2 边界框的僵化表示
广泛使用的边界框表示可以被视为目标框坐标的一种狄拉克δ分布形式。然而，它未能考虑到数据集中的模糊性和不确定性
![[DFL3.png]]
尽管一些研究将框模型化为**高斯分布，但这过于简单**，无法捕捉边界框位置的真实分布情况。**实际上，真实的分布可以更加随意和灵活，而无需像高斯函数那样具有对称性。**
# 2. 本文方法
## 2.1 对于定位质量的表示
本文提议将其与分类得分合并为一个单一且统一的表示形式：
- 一个分类向量，其中其在真实类别索引处的值对应于其相应的定位质量（在本文中通常是预测框与相应真实框之间的交并比得分）。
将分类得分和交并比得分统一为一个联合且单一的变量（称为“分类交并比联合表示”），该变量可以以端到端的方式进行训练，同时在推理过程中直接使用
![[DFL4.png]]
它消除了训练与测试的不一致性，并使定位质量与分类之间的相关性达到最强  
负样本将被赋予 0 的质量得分，从而使整体质量预测更加保密和可靠
![[DFL5.png]]

## 2.2 对于边界框的表示
本文提出通过直接学习其连续空间内的离散概率分布来表示边界框位置的任意分布（在本文中称为“一般分布”），而不引入任何其他更强的先验条件（例如高斯分布）
能够获得更可靠和准确的边界框估计值，同时还能了解其各种潜在的分布情况
![[DFL3.png]]
# 3. 本文方法带来的新问题
## 3.1 新问题
分类分支通常采用焦点损失（FL）进行优化。FL能够通过重新构造标准交叉熵损失来成功解决类别不平衡问题
但是本文方法带来：  
**作为监督的连续交并比标签（0∼1）的连续性，因为原始的 FL 目前仅支持离散的 {1， 0} 类别标签**
## 3.2 解决方案
通过将 FL 从离散版本扩展到其连续变体（称为广义焦点损失（GFL））成功解决了这个问题
### 3.2.1 GFL简述
与 FL 不同，GFL 考虑了一种更通用的情况，即全局优化解决方案能够针对任何所需的连续值，而不是离散值  
详细来说：  
- GFL 可以特化为质量焦点损失（QFL）和分布焦点损失（DFL），分别用于优化改进的两种表示形式：QFL 侧重于稀疏的一组困难示例，并同时生成其对应的类别上的连续 0∼1 质量估计；DFL 构建了这样一个网络，能够迅速专注于学习目标边界框在连续位置周围值的概率，且这种概率分布是任意且灵活的。
### 3.2.2 GFL 的三个优势
1. 当单阶段检测器通过附加的质量评估来增强自身时，它能够弥合训练与测试之间的差距，从而形成一种更简洁、联合且有效的分类与定位质量的表示方式  
2. 它能够很好地模拟边界框的灵活底层分布，从而提供更具信息量和更准确的框位置  
3. 单阶段检测器的性能能够持续得到提升，且不会引入额外的开销
