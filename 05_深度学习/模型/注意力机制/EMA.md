# 1. 出发点
CNN扩展到跨多个卷积层时，它表现出显著的增强学习特征表示的能力。然而，这会**导致堆叠更多的深度卷积对，并且需要消耗大量的内存和计算资源**，这是构建深度CNN的**主要缺点**。
- 作为一种替代方法，注意力机制方法由于其灵活的结构特性，不仅可以强化学习更有判别力的特征表示，而且可以很容易地嵌入到CNN的主干结构中
----
目前普遍认为主要有三种注意机制
1. 通道注意
2. 空间注意
3. 两者兼而有
## 2.1 通道注意力机制
作为通道注意力的代表，通道加权( SE )显式地模拟了跨维度的相互作用来提取通道注意力。  
卷积块注意力模块( CBAM ) ：利用特征图中空间和通道维度之间的语义相互依赖关系建立跨通道和跨空间信息。因此，CBAM在将跨维度注意力权重集成到输入特征方面表现出了巨大的潜力。  
- 问题：人工设计的池化操作涉及复杂的处理过程，会带来一定的计算开销。  
- 解决方式：使用特征分组方法在不同的资源上将特征分为多组。显然，它可以使每一组特征在空间上均匀分布。随后，空间点集分组配准增强( Spatial点集分组配准Enhanced，SGE )注意力将通道维度分组为多个子特征，并改进了不同语义子特征描述的空间分布，取得了突出的性能。
## 2.2 注意力机制设计
在做像素级任务（比如语义分割、深度估计这些需要对每个像素精确预测的任务）时，注意力模块该怎么设计才能又快又准？
- 传统的SE注意力（Squeeze-and-Excitation）：会把通道数压缩（比如从512维压到32维）再做注意力，这样计算量小，但信息丢得有点多。
- Coordinate Attention (CA)：比SE好一点，它在压缩通道的同时，还保留了位置（x方向和y方向）的信息，压缩比例选得合适的话，性能跟SE差不多甚至更好。
- Polarized Self-Attention (PSA)：它干脆把某个方向的通道直接“压扁”（完全压缩，不留中间维度），保留另一个方向的高分辨率信息。用很小的压缩比（几乎不怎么压缩）就能大幅提升性能。作者觉得这说明：在像素级任务里，太狠地压缩通道反而不好
- Efficient Channel Attention (ECA)：这个模块就反着来了——它几乎不压缩通道数（reduction ratio ≈ 1），照样又快又准，说明在某些情况下根本没必要压缩通道。
- Triplet Attention (TA)：它不走传统的“一条路走到底”，而是开了三个平行的分支（分别处理通道-高度、通道-宽度、通道-通道之间的关系），三个分支并行跑，最后再融合。这样跨维度的交互捕捉得更好，速度也更快。
- Shuffle Attention (SA)：把通道分成好几个小组（子特征），每个小组独立做注意力，然后再shuffle（洗牌）一下混合信息。这些小组可以并行计算，特别适合多核CPU/GPU，效率很高。
- ParNet（Parallel Network）：直接整个网络都搞成好几个并行的子网络一起跑，这样特征提取又快又高效，同时还能保持网络不太深、延迟低。
# 2. 本文方法
## 2.1 设计与结构
从前述注意力机制中得到启发，可以看出跨维度交互有助于通道或空间注意力预测  
基于分组结构，修正了CA的顺序处理方法，提出了一种新的无需降维的高效多尺度注意力( EMA )  
- 网络只有两个卷积核将分别放置在并行子网络中。其中一个并行子网络是1x1卷积核，其处理方式与CA相同，另一个是3x3卷积核。  
## 2.2 方法优势
1. 提出了一种新颖的跨空间学习方法，并设计了多尺度并行子网络来同时建立短程和长程依赖关系  
2. 考虑一种通用的方法，通过通用卷积将部分通道维度重塑为批量维度，以避免某种形式的降维。  
3. 除了在每个并行子网络中构建局部跨通道交互而不进行通道降维外，本文还通过跨空间学习方法将两个并行子网络的输出特征图进行融合
# 3. 总结
EMA就是目前性价比最高的轻量化注意力模块之一，几乎所有主流检测器（YOLOv5/v8/v9/v10、YOLO-NAS、RT-DETR、PP-YOLOE等）替换成EMA后，都能免费吃到1.5~3个点的mAP提升，而且速度基本不变甚至还略有下降延迟。
