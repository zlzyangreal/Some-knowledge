# 1. 出发点
提高CNN性能三个重要因素：深度、宽度和基数
- 基数不仅节省了参数总数，而且比深度和宽度这两个因素都具有更强的表示能力。
# 2. 本文方法
卷积注意力机制
由于卷积操作通过融合跨通道和空间信息来提取信息特征，我们采用我们的模块沿着通道和空间轴两个主要维度来强调有意义的特征。
![[CBAM1.png]]
依次应用通道和空间注意力模块，以便每个分支可以分别在通道和空间轴中学习"什么"和"在哪里"。模块通过学习哪些信息来强调或抑制，从而有效地帮助网络内的信息流动
- 具体来说：CBAM前馈卷积神经网络的注意力模块 - 给定一个中间特征图，我们的模块沿着通道和空间两个独立的维度依次推断注意力图，然后将注意力图与输入特征图相乘以进行自适应特征精修
