在 C 和 C++ 语言中，`char` 是一种基本数据类型，用于表示单个字符。它通常占用 1 个字节（8 位）的内存空间。
- **存储内容**：
    - `char` 类型可以存储单个字符，例如 `'a'`、`'1'`、`'@'` 等。
    - 在内存中，`char` 类型是以 ASCII 码（或扩展 ASCII 码）的形式存储的。例如，字符 `'a'` 的 ASCII 码是 97，字符 `'A'` 的 ASCII 码是 65。
- **有符号和无符号**：
    - 默认情况下，`char` 类型可能是有符号的（`signed char`），也可以是无符号的（`unsigned char`），这取决于编译器和平台。有符号的 `char` 类型可以表示 -128 到 127 的整数，无符号的 `char` 类型可以表示 0 到 255 的整数。
