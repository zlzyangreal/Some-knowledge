用于将一个以null终止的字符串转换为一个整数。这个函数读取字符串，忽略前导空格，然后解析尽可能多的数字字符，直到遇到非数字字符为止。
# 1.原型
```c
int atoi(const char *str);
```
参数说明：
- `str`：指向要转换的以null终止的字符串的指针。
返回值：
- `atoi` 返回转换的整数值。
# 2.例子
```c
#include <stdio.h>

int main() {
    const char *str = "123";
    int value = atoi(str);

    printf("The integer value is: %d\n", value);

    return 0;
}
```
`atoi` 函数将字符串 `"123"` 转换为整数 `123`
# 3.注意
1. **错误处理**：如果字符串不是一个有效的整数表示，`atoi` 函数不会提供错误信息。它只会返回一个整数，可能是0或者部分解析的数字。
2. **数值范围**：如果字符串表示的数值超出了 `int` 类型的范围，返回的结果可能会不正确，并且不会设置任何错误标志。
3. **前导符号**：`atoi` 函数忽略任何前导符号（'+' 或 '-'），只解析数字字符。
**由于这些限制，现代C和C++编程中更推荐使用 strtol**
