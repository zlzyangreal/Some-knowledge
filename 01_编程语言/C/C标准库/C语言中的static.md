# 1、**修饰局部变量**
静态局部变量的作用域仍然是所在的函数内部，其他函数无法访问。
- 与普通局部变量（自动变量）不同，静态局部变量的生命周期是**整个程序的运行期间**。它只在第一次进入定义它的函数时被**初始化一次**，之后每次进入该函数时，该变量都保留上一次函数调用结束时的值。
```c
void func() {
    static int count = 0;
    count++;
    printf("函数被调用的次数：%d\n", count);
}
//每次调用 func 函数时，count 都会在上一次的基础上递增，而不是每次都重新初始化为 0，从而实现了对函数调用次数的累计统计。
```
# 2、**修饰全局变量**
静态全局变量的作用域仅限于定义它的源文件内。其他源文件无法直接访问该静态全局变量，即使通过外部变量声明（`extern`）也无法访问。
- 静态全局变量的生命周期是整个程序的运行期间。
```c
// file1.c
static int config_value = 10;

void func1() {
    printf("config_value in func1: %d\n", config_value);
}

// 在 file2.c 中就无法直接访问 config_value，从而保证了数据的私有性。
```
# 3、**修饰函数**
被 `static` 修饰的函数称为静态函数，其作用域仅限于定义它的源文件内。其他源文件无法直接调用该静态函数，即使通过函数指针等方式也无法调用。
```c
// file1.c
static void helper_func() {
    // 辅助函数实现
}

void main_func() {
    helper_func();
}
//在 file2.c 中就无法直接调用 helper_func，从而避免了不必要的函数调用和潜在的命名冲突。
```
