`emplace_back` 是 C++11 引入的特性，它提供了一种在容器末尾构造新元素的方法，而不需要先构造一个临时对象。这可以减少不必要的复制或移动操作，从而提高性能。
# 1.原型
```cpp
void emplace_back(Args&&... args);
```
* 这里的 `Args&&... args` 表示参数列表，`Args` 是构造函数的参数类型，`...` 表示参数包，`&&` 表示参数作为右值引用传递。
# 2.例子
```cpp
#include <vector>

int main() {
    std::vector<int> v;
    v.emplace_back(10);  // 直接在容器末尾构造一个值为10的int
    v.emplace_back(20);  // 直接在容器末尾构造一个值为20的int

    return 0;
}
```
# 3.注意事项
1. **构造函数参数**：`emplace_back` 需要传递给元素构造函数的参数。如果传递的参数数量或类型不正确，将导致编译错误。
2. **内存分配**：如果容器没有足够的空间来存储新元素，`emplace_back` 可能会触发内存分配。这与 `push_back` 相同。
3. **异常安全性**：如果构造函数抛出异常，`emplace_back` 不会插入任何元素，容器的状态将保持不变。
4. **容器类型**：`emplace_back` 也适用于其他序列容器，如 `std::list` 和 `std::deque`，但它们的行为略有不同，因为它们不是连续存储的
# 4.相对于以前版本的优势
1. **避免不必要的复制或移动**：使用 `emplace_back` 可以直接在容器的内存中构造新元素，避免了构造临时对象然后再复制或移动到容器中的步骤。
2. **性能提升**：对于大型对象或复杂类型，使用 `emplace_back` 可以显著提高性能，因为它减少了对象的复制或移动操作。
3. **代码可读性**：使用 `emplace_back` 可以使代码更清晰，因为它直接展示了在容器中构造新元素的意图。
