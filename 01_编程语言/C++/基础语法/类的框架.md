## 类的框架
* 以复数为例
```cpp
class complex {
public:
    complex (double r = 0, double i = 0) : re (r), im (i)
    {}
    complex& oprator += (const complex&);
    double real () const { return re; }
    double imag () const { return im; }
private:
    double re, im;

    friend complex& __doapl (complex*, const complex&)
}
```
* `real ()` `imag ()`直接在类里定义了
* `complex& oprator += (const complex&);`只是一句声明
*  **公有成员（public）**：公有成员可以被类的外部代码访问，也就是类的对象可以直接访问公有成员。这使得公有成员成为类与外部世界交互的接口。
- **私有成员（private）**：私有成员只能在类的内部（类的成员函数）访问，外部代码无法直接访问私有成员。这种封装性确保了类的内部实现细节对外部是隐藏的。
