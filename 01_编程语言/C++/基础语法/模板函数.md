# 模板函数

> 一句话：把“类型”变成参数，让一份代码适配多种类型，编译期展开，运行时零开销。

## 1. 基本写法

```cpp
template <typename T>
T maxOf(const T& a, const T& b) {
    return a > b ? a : b;
}

maxOf(1, 2);          // T 推导为 int
maxOf(1.5, 2.5);      // T 推导为 double
maxOf<int>(1, 2.5);   // 显式指定，2.5 被转成 int
```

要点：

- 模板定义必须写在**头文件**里（或用 .ipp/.tpp 显式实例化），否则别的编译单元看不到函数体，链接期报 `undefined reference`。
- 类型推导时不做隐式转换：`maxOf(1, 2.5)` 会推导失败（T 既不是 int 也不是 double）。
- 传参用 `const T&` 避免大对象拷贝；小类型（int、指针）直接按值也无所谓。

## 2. 多类型参数与返回类型推导

```cpp
template <typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {   // C++11 尾置返回
    return a + b;
}

template <typename T, typename U>
auto add2(T a, U b) {                     // C++14 直接 auto 推导
    return a + b;
}
```

## 3. 特化：对某个类型给不同实现

```cpp
template <typename T>
bool isZero(T v) { return v == T{}; }

template <>
bool isZero<const char*>(const char* v) {   // 全特化
    return v == nullptr || *v == '\0';
}
```

偏特化只能用于**类模板**，函数模板只能全特化——这是常被面试问到的点。

## 4. 可变参数模板（C++11）

```cpp
template <typename... Args>
void printAll(Args&&... args) {
    ((std::cout << args << ' '), ...);   // C++17 折叠表达式
}
printAll(1, 2.5, "abc");
```

## 5. 常见坑

1. 模板写在 .cpp 里 → 其他文件链接不到。
2. 递归模板层数过深 → 编译时间爆炸 / 栈溢出。
3. 对模板参数做隐式类型转换会失败，要显式 `static_cast` 或 `<int>` 指定。
4. 报错信息几十行时，从**第一行**“template argument deduction failed”往下读，别从最后一行看。
