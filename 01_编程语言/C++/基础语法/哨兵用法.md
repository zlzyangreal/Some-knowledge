# 1.初始化哨兵
```cpp
#include <iostream>
#include <vector>
#include <limits>

int findMax(const std::vector<int>& arr) {
    int maxVal = std::numeric_limits<int>::min(); // 初始化哨兵
    for (int num : arr) {
        if (num > maxVal) {
            maxVal = num;
        }
    }
    return maxVal;
}

int main() {
    std::vector<int> nums = {3, 7, 1, 9, 5};
    std::cout << "Max = " << findMax(nums) << std::endl;
}

```
- 寻找最大值，这里 `maxVal` 取最小值作为为哨兵进行替换
# 2.边界哨兵
避免在循环里反复检查边界。  
比如：顺序查找数组中的元素，传统写法需要检查 `i < n`，但加个哨兵可以省掉。
```cpp
#include <iostream>
#include <vector>

int sentinelSearch(std::vector<int>& arr, int target) {
    int n = arr.size();
    arr.push_back(target); // 哨兵放在最后，避免越界

    int i = 0;
    while (arr[i] != target) {
        i++;
    }
    arr.pop_back(); // 恢复数组,指的是去掉加进去的8
    return (i < n) ? i : -1;
}

int main() {
    std::vector<int> nums = {1, 4, 6, 8, 10};
    std::cout << "Index of 8: " << sentinelSearch(nums, 8) << std::endl;
    std::cout << "Index of 5: " << sentinelSearch(nums, 5) << std::endl;
}

```
# 3.终止哨兵
用特殊值标记“结束”。  
典型例子就是 **C 风格字符串的 `'\0'`**：
```cpp
#include <iostream>

int strLength(const char* str) {
    int len = 0;
    while (str[len] != '\0') { // '\0' 就是终止哨兵
        len++;
    }
    return len;
}

int main() {
    const char* word = "hello";
    std::cout << "Length = " << strLength(word) << std::endl;
}

```
