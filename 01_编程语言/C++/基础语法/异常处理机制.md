在 C++ 里，`try` 和 `catch` 是 **异常处理机制** 的关键字。

# 1. 基本语法

```cpp
try {     
// 可能会抛出异常的代码
} catch (const std::exception& e) {     
// 捕获并处理异常 
}
```
- **try 块**：包裹可能出错的代码，如果里面抛出了异常（`throw`），就会跳到对应的 `catch` 块去处理。
- **catch 块**：用来捕获异常对象，并进行相应处理。
    - `catch (const std::exception& e)` 表示捕获所有继承自 `std::exception` 的异常，并通过 `e.what()` 获取错误信息。
# 2. eg

```cpp
try {
    std::string input;
    std::getline(std::cin, input);                   // 读取输入

    auto parsed = SubarrayChecker::parseInput(input); // 如果输入不合法，这里会 throw
}
catch (const std::exception& ex) {
    std::cerr << "Error: " << ex.what() << '\n';     // 捕获并打印错误信息
    return 1;                                        // 非正常退出
}

```
