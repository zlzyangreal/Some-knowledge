# 1. 主要类别与作用（对应冈萨雷斯教材）

## 1.1 简单描述子
- **面积**：区域像素总数。最直接的尺寸度量，用于过滤过大或过小的无关区域。
- **周长**：区域边界长度。与面积结合可计算其他复杂描述子。
- **致密性**：`(周长)² / 面积`。衡量形状的紧凑程度，圆形的致密性最小（~12.56）。
## 1.2 形状描述子
- **偏心率（长宽比）**：区域主轴与辅轴长度之比。**这是您流程中识别“细长”结构的关键**。
- **欧拉数**：`欧拉数 = 连通分量数 - 孔洞数`。一个简单的拓扑描述子，描述区域的“连通性”结构。
## 1.3 矩描述子
这是更强大的数学工具，用于描述区域的全局形状。
- **空间矩**：基础矩，用于计算质心等。
- **中心矩**：平移不变，即物体在图像中移动位置不影响矩的值。
- **Hu不变矩**：一组7个矩函数，具有**平移、缩放和旋转不变性**。即使物体被移动、放大缩小或旋转，这些矩的值也基本不变，常用于**模板匹配**和**形状识别**。
## 1.4 方向描述子
- **主轴方向**：**在您流程中用于判断边缘的朝向**。它定义为使区域二阶矩最小的轴的方向，可以理解为区域“延伸”的方向。
# 2. 作用
区域描述子是一组**从二值图像中已分割出的区域（连通分量）计算出的量化特征**。它的作用是将一个区域的**视觉属性**（形状、大小、方向等）转化为**可计算的数值**，为后续的分类、识别和筛选提供依据。
