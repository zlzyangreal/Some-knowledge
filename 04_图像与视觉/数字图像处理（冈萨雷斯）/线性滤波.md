## 4.1 线性滤波的数学形式

线性空间滤波 = **邻域加权求和**，也就是相关/卷积：

```
g(x, y) = ΣΣ w(s, t) · f(x + s, y + t)      (相关)
g(x, y) = ΣΣ w(s, t) · f(x - s, y - t)      (卷积，核先翻转 180°)
```

- **相关**：核不翻转，模板匹配、特征检测常用。
- **卷积**：核翻转，具有交换律/结合律，信号处理的理论工具。
- 对称核（如高斯、均值）两者结果相同，所以工程上常混着说。

## 4.2 常用平滑核

| 核 | 作用 | 特点 |
| --- | --- | --- |
| 均值核（全 1 / n） | 简单平滑 | 会明显模糊边缘 |
| 高斯核 | 加权平滑（中心权重大） | 可分离（先横后竖），接近自然模糊 |
| 中值滤波 | 取邻域中位数 | **非线性**，去椒盐噪声最强，不模糊边缘 |

```python
import cv2
blur  = cv2.blur(img, (5, 5))                                  # 均值
gauss = cv2.GaussianBlur(img, (5, 5), sigmaX=1.5)               # 高斯
med   = cv2.medianBlur(img, 5)                                  # 中值（非线性）
```

## 4.3 边界怎么处理

卷积核在图像边缘会“越界”，常见填充方式：

| 方式 | 说明 | OpenCV 常量 |
| --- | --- | --- |
| 补零 | 外边全 0 | `BORDER_CONSTANT` |
| 复制边缘 | 重复最外圈像素 | `BORDER_REPLICATE` |
| 镜像 | 以边缘为轴翻转 | `BORDER_REFLECT` / `BORDER_REFLECT_101` |
| 环绕 | 从对边取 | `BORDER_WRAP` |

补零会在边缘产生暗边，一般用复制或镜像。

## 4.4 锐化 = 原图 + 高频

拉普拉斯算子提取高频，再叠回原图：

```python
import numpy as np, cv2
lap = cv2.Laplacian(img, cv2.CV_32F, ksize=3)
sharp = cv2.addWeighted(img.astype(np.float32), 1.0, lap, -1.0, 0)
```

这也是“非锐化掩蔽（unsharp mask）”的原理：`原图 + k × (原图 - 模糊)`。
