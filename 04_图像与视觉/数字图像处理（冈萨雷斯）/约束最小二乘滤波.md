# 2. 约束最小二乘的核心机制（图解思路）
```txt
目标：最小化 ||g - h * f̂||²  (数据保真项)
约束：||p * f̂||² = ||n||²     (平滑约束项，p为高通算子)

→ 引入拉格朗日乘子 γ → 自动搜索 γ 使约束成立
```
```txt
频域：
Ĝ(u,v) = [H*(u,v) / (|H|² + γ|P|²)] G(u,v)
       ↑
       W_cls(u,v)：CLS 滤波器
```
![[图像复原与重建15.png]]
- **一句话总结就是不需要求 `K` ，自动求 `γ`**
# 3. Code
```python
from skimage import restoration
import cv2
import numpy as np

def cls_deblur_skimage(img, kernel):
    """
    使用 skimage 实现约束最小二乘（自动求 γ）
    img    : 退化图像 (float32, 0-1)
    kernel : PSF 核 (已归一化)
    """
    # 构造 PSF 矩阵
    psf = np.zeros_like(img)
    kh, kw = kernel.shape
    psf[:kh, :kw] = kernel
    
    # unsupervised_wiener = 约束最小二乘
    restored, _ = restoration.unsupervised_wiener(img, psf)
    return np.clip(restored, 0, 1)
```
