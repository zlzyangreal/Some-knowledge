作用：找出图像中灰度剧烈变化的位置，得到物体边界
[[python_opencv Canny边缘检测]]

## 1. 原理

边缘 = 灰度的一阶导数极值 / 二阶导数过零点。所以边缘检测本质是**求梯度**：

```
|∇f| = sqrt(Gx² + Gy²) ≈ |Gx| + |Gy|
θ    = arctan(Gy / Gx)        （梯度方向，与边缘方向垂直）
```

## 2. 经典算子对比

| 算子 | 模板特点 | 优点 | 缺点 |
| --- | --- | --- | --- |
| Roberts | 2×2 对角差分 | 最快 | 对噪声极敏感，无方向平滑 |
| Prewitt | 3×3，权重全 1 | 有平滑 | 平滑过于均匀 |
| Sobel | 3×3，权重 1-2-1 | 平滑更合理，抗噪较好 | 边缘较粗 |
| Laplacian | 二阶差分 | 各向同性、定位准 | 对噪声极敏感，需先平滑（LoG） |
| Canny | 高斯 + 梯度 + 非极大值抑制 + 双阈值 | 单像素宽、连续、抗噪 | 参数（双阈值）需调 |

## 3. Canny 四步（务必能背）

1. **高斯平滑**：去噪，`sigma` 越大越平滑。
2. **计算梯度**：Sobel 求 `Gx, Gy` 与幅值/方向。
3. **非极大值抑制（NMS）**：沿梯度方向只保留局部最大，把粗边压成单像素。
4. **双阈值 + 滞后连接**：高于高阈值→强边缘；低于低阈值→丢弃；介于两者且与强边缘相连→保留。

```python
import cv2
gray  = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur  = cv2.GaussianBlur(gray, (5, 5), 1.4)
edges = cv2.Canny(blur, threshold1=50, threshold2=150)   # 低:高 ≈ 1:2 ~ 1:3
```

参数经验：`threshold1:threshold2` 取 1:2 或 1:3；噪声大就加大 `sigma` 并提高阈值。

## 4. Sobel / Laplacian 代码

```python
import numpy as np
gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)   # 水平方向梯度
gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)
mag = cv2.magnitude(gx, gy)
mag = cv2.normalize(mag, None, 0, 255, cv2.NORM_MINMAX).astype(np.uint8)

lap = cv2.Laplacian(cv2.GaussianBlur(gray, (3, 3), 0), cv2.CV_32F, ksize=3)  # LoG
```

## 5. 选型建议

- 要**单像素、连续**轮廓 → Canny。
- 要**快**、跑在 MCU 上 → Sobel + 阈值。
- 要**亚像素定位**（标定、测量）→ 拟合并求亚像素极值，或用 [[EDLines]]、[[LSD]] 这类直线检测。
- 边缘碎、闭合差 → 先形态学闭运算连接，再提取轮廓（见 [[开运算与闭运算]]、[[连通分量的提取]]）。
