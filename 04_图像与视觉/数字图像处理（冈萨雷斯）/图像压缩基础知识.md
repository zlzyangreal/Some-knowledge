# 1.**为什么要压缩？**
- 图像数据量大：一幅 1024×1024 灰度图 = 1MB，彩色 = 3MB。
- 目标：**减少存储空间 + 加快传输速度**，同时控制质量损失。
> **项目要点**：压缩比 = 原始字节数 ÷ 压缩后字节数。 例如 10:1 表示文件变 1/10 大小。

# 4. 保真度衡量标准
## 4.1 Code
```python
import numpy as np

def mse(original, compressed):
    return np.mean((original - compressed) ** 2)

def psnr(original, compressed):
    mse_val = mse(original, compressed)
    if mse_val == 0: return float('inf')
    return 20 * np.log10(255 / np.sqrt(mse_val))
```
## 4.2 系数
- **MSE**：越小越好（0=无失真）
- **PSNR**：越高越好
    - > 40dB：人眼几乎看不出差别    
    - 30~40dB：轻微失真
    - <30dB：明显块效应
# 5. 信息论基础
- 熵（Entropy）：表示一幅图的“信息量下限”
```python
from collections import Counter
import numpy as np

probs = np.bincount(img.flatten(), minlength=256) / img.size
probs = probs[probs > 0]
entropy = -np.sum(probs * np.log2(probs))
print(f"Entropy: {entropy:.2f} bits/pixel")
```
- 熵 = 压缩的理论极限（无损情况）
- 项目意义： 熵 4.2 → 理论上 1 像素最多能压到 4.2 位（原8位）
