# 2. 维纳滤波的核心机制（图解思路）
```txt
频域：
G(u,v) = F(u,v) * H(u,v) + N(u,v)

维纳滤波器 W(u,v) = H*(u,v) / (|H(u,v)|² + K)

┌─────────┐    ┌─────────┐    ┌─────────┐
│   G     │ →  │   W     │ →  │   Ĝ     │ → IFFT → 复原图
└─────────┘    └─────────┘    └─────────┘
```

## 2.1 维纳滤波的“刹车逻辑”（K 的作用）
![[图像复原与重建10.png]]
- K 越大 → 复原越保守 → 越平滑 → 越抗噪
# 3. Code
```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def wiener_deblur(img, kernel, K=0.01):
    """
    维纳滤波复原
    img     : 退化图像 (float32, 0-1)
    kernel  : PSF 核 (已归一化)
    K       : 噪声功率比 (刹车系数)
    """
    h, w = img.shape
    kh, kw = kernel.shape
    
    # Step 1: 零填充防边界混叠
    pad_h = h + kh - 1
    pad_w = w + kw - 1
    img_pad = np.pad(img, ((0, pad_h-h), (0, pad_w-w)), 'constant')
    kernel_pad = np.pad(kernel, ((0, pad_h-kh), (0, pad_w-kw)), 'constant')
    
    # Step 2: 频域运算
    G = np.fft.fft2(img_pad)
    H = np.fft.fft2(kernel_pad)
    H_conj = np.conj(H)
    
    # Step 3: 维纳滤波器
    H_mag2 = np.abs(H)**2
    W = H_conj / (H_mag2 + K)  # 核心公式
    
    # Step 4: 复原 + IFFT
    F_restored = G * W
    result = np.real(np.fft.ifft2(F_restored))
    
    # Step 5: 裁剪回原尺寸
    return result[:h, :w]
```
