由投影重建图像是“从物体在多个角度的投影数据（X射线、雷达、超声等），通过数学反演重建原始二维/三维图像的过程”。
- **输入**：一组 **平行束投影**（如 Radon 变换）
- **输出**：原始物体截面图像
- **典型应用**：**CT 扫描、MRI、工业无损检测**

# 3. 滤波反投影（FBP）算法流程（图解）
```txt
投影数据 p(θ, t)
     ↓
1️⃣ 滤波（Ramp 滤波器 |H(f)| = |f|）
     ↓
2️⃣ 反投影（沿 θ 方向涂抹）
     ↓
3️⃣ 所有 θ 叠加 → 重建图像
```
# 4. Code
```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def radon_transform(img, angles):
    """计算多角度投影"""
    h, w = img.shape
    max_dist = int(np.ceil(np.sqrt(h**2 + w**2)))
    sinogram = np.zeros((len(angles), 2*max_dist))
    
    for i, theta in enumerate(angles):
        rot = cv2.warpAffine(img, cv2.getRotationMatrix2D((w//2, h//2), theta, 1),
                             (w, h), flags=cv2.INTER_LINEAR, borderMode=cv2.BORDER_CONSTANT)
        projection = np.sum(rot, axis=0)
        sinogram[i, max_dist - w//2 : max_dist - w//2 + w] = projection
    
    return sinogram, max_dist
```
