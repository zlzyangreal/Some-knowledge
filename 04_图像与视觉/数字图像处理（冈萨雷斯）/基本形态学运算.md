## 1. 两个基本操作

记结构元素为 `B`：

- **腐蚀** `A ⊖ B`：B 完全落在 A 内时，中心点保留 → 前景**变细/变小**，去掉小亮点、断开细连接。
- **膨胀** `A ⊕ B`：B 与 A 有交集时，中心点置为前景 → 前景**变粗/变大**，填补小孔、连接断裂。

```python
import cv2, numpy as np
kernel = np.ones((3, 3), np.uint8)

erode  = cv2.erode(img, kernel, iterations=1)
dilate = cv2.dilate(img, kernel, iterations=1)
```

## 2. 组合运算

| 运算 | 定义 | 效果 | 典型用途 |
| --- | --- | --- | --- |
| 开运算 | 先腐蚀后膨胀 | 去掉小突出/毛刺，主体大小不变 | 去噪点、分离粘连物体 |
| 闭运算 | 先膨胀后腐蚀 | 填补小孔/裂缝，主体大小不变 | 连接断裂边缘、填空洞 |
| 形态学梯度 | 膨胀 − 腐蚀 | 得到外轮廓 | 提取边界 |
| 顶帽 | 原图 − 开运算 | 突出比背景亮的细小结构 | 提取亮小目标 |
| 黑帽 | 闭运算 − 原图 | 突出暗细小结构 | 提取暗小缺陷 |

```python
opening = cv2.morphologyEx(img, cv2.MORPH_OPEN,  kernel)
closing = cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel)
grad    = cv2.morphologyEx(img, cv2.MORPH_GRADIENT, kernel)
tophat  = cv2.morphologyEx(img, cv2.MORPH_TOPHAT, kernel)
blackhat= cv2.morphologyEx(img, cv2.MORPH_BLACKHAT, kernel)
```

## 3. 结构元素怎么选

- **形状**：矩形（快）、椭圆（各向同性，去噪常用）、十字（保留水平垂直结构）。
- **尺寸**：比要去掉的目标稍大一点。想删掉 ≤ 5 像素的噪点，就用 5×5 或 7×7。
- **迭代次数**：`iterations=n` 等价于连续做 n 次，比直接放大核更“圆”。

## 5. 工程套路

```python
# 缺陷检测里最常见的预处理链
binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)[1]
binary = cv2.morphologyEx(binary, cv2.MORPH_OPEN,  np.ones((3, 3), np.uint8))   # 去噪点
binary = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, np.ones((5, 5), np.uint8))   # 连断线
cnts, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
```
