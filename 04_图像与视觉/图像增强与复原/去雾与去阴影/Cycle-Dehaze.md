# 1.单幅图像去雾方法局限
单幅图像去雾方法可分为基于先验信息的方法和基于学习的方法
## 1.1 基于先验信息的方法
主要通过利用先验信息（如暗通道先验、颜色衰减先验、雾线先验）来估计大气散射模型的参数  
- 这些参数是通过基于学习的方法从训练数据中获取的，这些方法主要依赖于深度学习方法
	- 深度学习方法都采用了对中间参数（例如传输图和大气光）的估计；**对抗网络（GANs）方法，它们构建模型时并不依赖于这些中间参数**
# 2. Cycle-Dehaze
1. 该网络是端到端网络  
2. 该网络无需使用带有对应真实图像的模糊图像对进行训练。通过非配对的方式（即仅使用清晰图像和模糊图像）来训练网络。  
3. 该网络是对 CycleGAN 架构进行了改进，以实现单幅图像的去雾处理，方法是在循环一致性损失的基础上，还加入了循环感知一致性损失。  
4. 该方法在训练和测试阶段既不需要带有真实图像的模糊图像样本，也不需要大气散射模型的任何参数  
5. 该方法提出了一种简单且高效的图像放大去雾技术，该技术借助拉普拉斯金字塔来实现图像的放大处理
