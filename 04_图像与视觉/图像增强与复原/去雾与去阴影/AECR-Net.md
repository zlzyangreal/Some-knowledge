# 1.现有问题（2021）
近些年提出的端到端去雾网络  
手段：通过一个去雾网络直接学习从朦胧图像到清晰图像的转换，从而简化去雾问题
## 1.1 仅采用清晰图像作为正样本来指导去雾网络的训练，而未利用负面信息；
![[AECR-Net1.png]]
- 仅图像重建损失无法有效地处理图像的细节，这可能会导致恢复图像中的颜色失真
### 1.1.1 基于正样本的额外知识正则化去雾（改进方法）
模型生成更自然的恢复图像
简介：从教师提取的正图像的中间表示中传递知识，并作为基于正样本的正则化输入到学生/去雾网络中
缺陷：尽管他们将正图像的信息用作上限值，但由于未利用负图像的信息作为下限值
![[AECR-Net2.png]]
- 仍然会出现伪影或不理想的结果
# 2. AECR-Net网络简介
![[AECR-Net3.png]]
## 2.1 CR（右图）
1. 文章方法将一幅朦胧图像、由去雾网络生成的其对应的恢复图像以及其清晰图像（即真实图像）分别标记为负样本、锚样本和正样本  
- 存在两种“对立的力量”；一种将预测值拉向清晰图像，另一种则在表示空间中将预测值推离朦胧图像  
2. CR 通过对比学习将锚样本约束在闭合的上下界内，这更有利于去雾网络逼近正样本图像并远离负样本图像  
3. CR 在测试阶段无需引入额外的计算/参数即可提高图像去雾的性能，因为它可以直接用于推理而不必保留。
## 2.2 AECR-Net（左图）
**通过将对比度正则化引入到所提出的类似于自动编码器的去雾网络中，将所提出的图像去雾框架称为 AECR-Net**
1. 类似于自动编码器（AE）的框架开发了一个紧凑的去雾网络，以在低分辨率空间中进行密集卷积计算，并减少层数  
2. 参数的减少而造成的信息损失可以通过自适应混合和动态特征增强（DFE）来弥补  
3. 自适应混合使来自下采样部分的浅层特征的信息能够适应性地流向来自上采样部分的高级特征，这对于特征保留非常有效  
4. 受到具有强大变换建模能力的可变形卷积的启发，DFE 模块动态地扩大了融合更多空间结构信息的感知范围，这显著提高了我们去雾网络的性能
