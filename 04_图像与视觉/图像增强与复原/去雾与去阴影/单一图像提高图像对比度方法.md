# 1.文中提到其他方法及缺陷（2008）
## 1.1 方法：偏振滤镜
### 1.1.1 思路
利用同一场景的两张或多张具有不同偏振度（DOP）的图像
- 图像获得一般手段：  通过旋转安装在相机上的偏振滤镜而获得的
### 1.1.2 缺陷
对于动态场景（其变化速度比滤镜旋转速度更快），这些方法无法用于寻找最大和最小的偏振度
## 1.2 方法：利用从恶劣天气场景中拍摄的多张图像
### 1.2.1 原理
利用同一场景中两张或更多张具有不同参与介质特性的图像之间的差异  
### 1.2.2缺陷
无法立即提供结果（必须等到介质的特性发生变化时才能得到结果）

**前两种方法都没办法处理动态场景**

## 1.3 方法：使用一张图像，并要求获取输入场景的近似三维几何模型
### 1.3.1 缺陷
对近似三维几何模型的要求存在问题，因为现实世界的结构（无论是自然场景还是人造场景）都存在显著的差异；  
**无法自动化**
# 2.方法简述
## 1.1 该方法必要条件
1. 可见度增强（或晴天）的图像比受恶劣天气影响的图像具有更高的对比度
2. 大气光的变化主要取决于物体与观察者之间的距离，因此通常较为**平滑**
## 1.3 简略描述
1. 估算大气光，从而可以获取光的色度  
2. 利用光的色度，我们去除输入图像的光色  
3. 每个像素计算数据成本和平滑度成本  
- 平滑度成本是根据相邻两个像素的标签（其值与大气光值相同）之间的差异或距离来计算的  
4. 这些数据和平滑度成本构成了完整的MRFs模型，可以使用现有的推理方法进行优化，从而得出大气光的估计值  
5. 基于估计的大气光，最后我们计算代表增强可见度场景的直接衰减
## 1.4 注意
本方法无意完全恢复场景的原始颜色或反照率。我们的目标仅仅是增强输入图像的对比度，从而提高图像的可见度。
