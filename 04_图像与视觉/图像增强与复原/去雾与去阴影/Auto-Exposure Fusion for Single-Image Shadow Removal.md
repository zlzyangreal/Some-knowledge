# 1. 阴影导致的问题
阴影区域所呈现的**随空间变化的色彩和光照失真**
阴影投射会降低图像的质量  
具体来说：导致颜色和光照的退化
# 2.当前其他解决方案弊端
## 2.1先前的阴影去除：  
1. 基于成对的有阴影和无阴影图像的物理阴影模型来进行建模  
2. 基于生成对抗网络（GAN）将它建模为图像到图像的转换问题，用于处理不成对的有阴影和无阴影图像
### 2.1.1 对抗网络在阴影去除的问题：要求数据采集稳定
1. 所学习到的阴影去除转换往往会生成**伪影和图像模糊**  
2. 存在数据分布要求的问题，即它们期望不成对的有阴影和无阴影图像集具有统计相似性
### 2.1.2 CNN网络阴影去除挑战： 
1. 阴影去除是依赖背景，要求 DNN 不仅要恢复有阴影区域的光照和色彩一致性，还要保留阴影下方的底层内容。阴影区域的空间变化特性要求融合过程必须足够“智能”，能够从各种图像中自适应地选择所需的过度曝光像素，以获得最终的无阴影版本。  
2. 由于阴影图案在边界和阴影区域内部存在不一致的情况，很难获得无痕迹的背景。
# 3.该方法
![[曝光去阴影.png]]
自动融合曝光网络  
原理：利用曝光估计来通过为阴影区域应用不同的曝光级别来生成多幅过度曝光图像
具体：将过度曝光的图像与原始阴影图像融合在一起，可以得到所需的无阴影图像  ；**多次过度曝光融合**具有更高的灵活性，并能提供更好的补偿阴影区域使其与非阴影区域具有相同的颜色和光照

| 算法                       | 方式                          | 作用           |
| ------------------------ | --------------------------- | ------------ |
| Shadow-aware FusionNet   | 阴影图像作为输入，在所有过度曝光图像之间生成融合权重图 | **解决CNN挑战1** |
| boundary-aware RefineNet | 具有边界感知功能的细化网络               | 进一步消除剩余的阴影痕迹 |
