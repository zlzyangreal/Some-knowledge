# 1.论文研究的问题（合成数据集在实际运用的局限）
大多数方法在合成的有雾图像上训练去雾模型，由于领域偏移，这些模型在推广到真实有雾图像时效果不佳
由于训练需要大量数据，但是获取不容易，大多数去雾模型都依靠在合成的雾霾数据集上进行训练。由于领域转移问题，从合成数据中学习到的模型往往无法很好地泛化到真实数据上
# 2.本文方法
![[图像转换去雾1.png]]
## 2.1 模型框架
框架包含两个部分：  
图像转换模块和两个与领域相关的去雾模块（一个用于合成领域，另一个用于真实领域）
## 2.2 实现手段
1. **为了减少不同领域的差异**，本文方法首先**使用双向图像转换网络将图像从一个领域转换到另一个领域**。由于图像雾化是一种噪声，并且高度依赖于场景深度，本文将深度信息纳入转换网络中，以指导从合成雾化图像到真实雾化图像的转换
2. 与领域相关的去雾网络使用该领域的图像（包括原始图像和转换后的图像）作为输入来执行图像去雾  
3. **使用一致性损失来确保两个去雾网络生成一致**
4. 为了进一步提高网络在真实领域的泛化能力，本文将真实雾化图像纳入训练中  
	- 希望真实雾霾图像的去雾处理结果能够具备清晰图像的一些特性，比如暗通道先验和图像梯度平滑
5. 采用端到端的方式训练图像转换网络和去雾网络，以便它们能够相互促进
