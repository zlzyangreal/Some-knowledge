# 1.本文针对问题
假设下采样模糊核是已知且预先定义的是不可取的，在实际应用中涉及的模糊核通常是复杂且不可获取的
## 1.1 多数SR方法
1. 方法：利用自然图像的自相似性特性来预测底层模糊核  
2. 缺陷：预测很容易受到输入噪声的影响，从而导致模糊核估计的不准确
## 1.2 本文出发点
原理：由核不匹配引起的伪影具有一定的规律性模式
![[IKC1.png]]
- 核（模糊核，预先估计的）不匹配的现象会引入不期望的伪影到输出图像中  
但是**如果输入的核比真实核更平滑，那么输出图像就会变得模糊/过度平滑。相反，如果输入的核比正确的核更锐利，那么结果就会过度变形，伴有明显的振铃效应**
# 2.本文提出方法
## 2.1 盲图像超分辨率的迭代核校正方法（IKC）  
通过观察之前的超分辨率结果，对估计的核进行迭代校正，逐渐接近真实值。即使预测的模糊核与真实核略有不同，输出图像也能消除由核不匹配引起的那些规律性伪影。
## 2.2 SFTMD
针对多个模糊核提出的 SR 方法（例如 SRMD ），本文发现将图像与模糊核的组合作为输入并非最佳选择。为了向前迈进一步，本文采用了空间特征变换（SFT）层 并提出了一个针对多个模糊核的高级 CNN 结构
