1. **功能**：`waitKey` 会阻塞程序的执行，直到用户按下一个键，或者超过指定的等待时间（毫秒）。
2. **参数**：`waitKey` **接受一个整数参数**，表示等待键盘输入的超时时间（以毫秒为单位）。如果参数是正数，函数会等待直到一个键被按下或者直到超时。如果参数是负数，函数会无限期地等待一个键按下。参数为 0 时，`waitKey` 会立即返回，不管是否有键被按下。
3. **返回值**：`waitKey` 返回按下的键的 ASCII 码。如果没有键按下，它返回 `-1`。
**eg**
```cpp
char key = cv::waitKey(30); // 等待最多30毫秒的键盘输入
if (key == 27) { // ASCII码27是Esc键
    break; // 退出循环
}
// 13 是回车
// 32 是空格
```
