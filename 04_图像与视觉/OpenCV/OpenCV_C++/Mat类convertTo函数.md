`convertTo` 是 OpenCV 库中 `cv::Mat` 类的一个成员函数，用于将矩阵转换为不同的数据类型。这个函数非常有用，因为它允许你将图像或其他矩阵的数据类型从一种格式转换为另一种格式，以适应不同的处理需求或算法要求。
# 函数的基本语法如下：
```cpp
void Mat::convertTo(OutputArray dst, int rtype, double alpha=1, double beta=0);
```
参数说明：
- `dst`：目标矩阵，转换后的矩阵将被存储在这里。类型为 `cv::OutputArray`。
- `rtype`：目标矩阵的数据类型，使用 OpenCV 的类型枚举来指定，例如 `CV_32F` 表示32位浮点数。
- `alpha`（可选）：缩放系数，用于在转换过程中对矩阵的每个元素乘以这个系数，默认值为1。
- `beta`（可选）：加上的常数项，用于在缩放后对矩阵的每个元素加上这个值，默认值为0。
# 使用 `convertTo` 可以执行如下操作：
- 将图像从 `CV_8UC3`（8位无符号整型的三通道彩色图像）转换为 `CV_32FC3`（32位浮点型的三通道彩色图像），以进行更高精度的图像处理。
- 标准化图像数据，例如将像素值从 [0, 255] 转换到 [0, 1] 范围内，这可以通过设置 `alpha=1/255` 和 `beta=0` 来实现。
- 改变图像的存储格式，比如从无符号整型转换为有符号整型。
