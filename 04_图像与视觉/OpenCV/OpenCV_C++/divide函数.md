在 OpenCV 中，`divide` 函数用于执行两个矩阵的元素级除法操作。这个函数可以处理不同大小和类型的矩阵，并且支持标量值与矩阵之间的除法。
# 函数的基本语法如下：
```cpp
void divide(InputArray src1, InputArray src2, OutputArray dst, double scale=1, int dtype=-1);
```
参数说明：
- `src1`：第一个输入矩阵或标量值，即被除数。
- `src2`：第二个输入矩阵或标量值，即除数。如果 `src2` 是一个矩阵，那么 `src1` 和 `src2` 必须具有相同的大小和类型，或者 `src2` 可以是一个标量全为1的矩阵。
- `dst`：目标矩阵，存储除法操作的结果。类型由 `dtype` 参数指定，如果 `dtype` 为 -1，则目标矩阵的数据类型与 `src1` 相同。
- `scale`（可选）：一个缩放因子，用于在除法操作之前对 `src1` 进行缩放。默认值为1。
- `dtype`（可选）：目标矩阵的数据类型，使用 OpenCV 的类型枚举来指定，例如 `CV_32F`。如果 `dtype` 为 -1，目标矩阵的数据类型将根据操作自动确定。
# `divide` 函数可以用于如下场景：
- 执行两个图像或矩阵之间的元素级除法。
- 将矩阵中的每个元素除以一个标量值。
- 在归一化过程中，将矩阵的像素值除以255以转换到` [0,1] `范围内。
