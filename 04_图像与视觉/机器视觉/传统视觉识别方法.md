## 1. 传统视觉识别的完整流水线

```
图像 → 预处理（灰度/滤波/增强） → 特征提取 → 特征匹配/分类 → 几何校验（RANSAC） → 输出
```

## 2. 特征点四大件

| 算法 | 检测什么 | 优点 | 缺点 |
| --- | --- | --- | --- |
| Harris | 角点（自相关矩阵两个特征值都大） | 快、旋转不变 | 不具尺度不变性 |
| FAST | 圆周上连续亮暗像素 | 极快，实时首选 | 无方向、无尺度，需配 BRIEF |
| SIFT | 高斯差分极值 + 128 维描述子 | 尺度/旋转/亮度不变，鲁棒 | 慢，有专利（2020 已过期） |
| ORB | FAST 检测 + BRIEF 描述子 + 方向 | 快且带方向，免费 | 大尺度变化时弱于 SIFT |

## 3. 匹配与校验

```python
import cv2

orb = cv2.ORB_create(nfeatures=1000)
kp1, des1 = orb.detectAndCompute(img1, None)
kp2, des2 = orb.detectAndCompute(img2, None)

bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches = sorted(bf.match(des1, des2), key=lambda m: m.distance)[:50]

# 用 RANSAC 剔除外点并求单应矩阵
src = np.float32([kp1[m.queryIdx].pt for m in matches]).reshape(-1, 1, 2)
dst = np.float32([kp2[m.trainIdx].pt for m in matches]).reshape(-1, 1, 2)
H, mask = cv2.findHomography(src, dst, cv2.RANSAC, 5.0)
```

要点：

- 匹配后**一定要用 RANSAC/几何校验**，否则错配会毁掉所有结果。
- `crossCheck=True` 或 Lowe's ratio test（`knnMatch` + `distance < 0.75 * next_distance`）用来初筛。
- 模板匹配（`cv2.matchTemplate`）只适合**尺度/旋转不变**的场景，否则用特征点。

## 4. 什么时候不要用深度学习

- 目标形状规则、光照稳定、算力有限（MCU/低端 ARM）→ 传统方法更稳更省。
- 需要**可解释**（每个判定都能说出依据）→ 传统方法天然可解释。
- 缺陷样本极少（只有几张良品图）→ 传统阈值/形态学 + 规则往往比硬训一个网络更现实。
